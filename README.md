# 个人使用的nixos nixpkgs flake输入镜像   
我使用NixOS主要追求的是声明式配置，不太在乎可复现性。    
由于储存涨价的大势所趋（雾），如果每个项目使用来自上游的独立的nixpkgs输入的话，可能会安装不同的版本，造成存储占用过大。   
本镜像每周会同步一次，这是我个人比较能接受的更新频率。   

## 注意：每次同步都会强制覆盖提交历史，只保留最新提交，如果追求可复现性，切勿使用本输入源！ 

# 2026.10.28更新：新增frozen系列源
一些软件包我实在不想频繁更新， frozen/*分支的镜像更新只能手动执行，会长期冻结在某个输入，可能不定期更新一次。
